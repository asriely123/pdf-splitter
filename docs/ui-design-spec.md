# UI 设计规范（Design Spec）

## 1. 设计关键词

淡粉、可爱、柔和、圆润、轻盈。避免俗气的高饱和粉；整体像一块草莓牛奶蛋糕，干净不腻。

## 2. 设计 Token（唯一颜色来源）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--pink-bg` | `#FFF5F9` | 窗口背景 |
| `--pink-card` | `#FFEAF2` | 卡片/拖拽区背景 |
| `--pink-border` | `#FFD3E3` | 卡片边框、分隔线 |
| `--pink-accent` | `#F4A0C0` | 主按钮、强调元素 |
| `--pink-deep` | `#E57CA6` | 按下态、选中态、拖入高亮 |
| `--ink` | `#6B4557` | 主文字 |
| `--ink-soft` | `#A98998` | 次要文字 |
| `--success` | `#7FBF9D` | 成功状态 |
| `--error` | `#E36B8C` | 错误提示、抖动输入框 |

其他颜色、透明色和阴影一律在 `:root` 中以语义化派生 Token 定义，组件内禁止直接使用任意色值。

## 3. 字体与排版

- 字体栈：`"Microsoft YaHei UI", "Microsoft YaHei", "Segoe UI", sans-serif`。
- 正文 14px，次要说明 12px，文件标题 15px 加粗，窗口标题 13px。
- 数字输入框文字 16px，等宽数字（`font-variant-numeric: tabular-nums`）避免跳动。

## 4. 形状与阴影

- 卡片圆角 16px，拖拽区圆角 20px，按钮圆角 12px，输入框圆角 10px。
- 卡片阴影：`0 4px 16px rgba(244, 160, 192, 0.16)`；hover 加深至 0.24。
- 标题栏高 46px，可拖动区域全宽，按钮区域 `-webkit-app-region: no-drag`。

## 5. 组件规范

### 标题栏

- 左侧显示应用名「PDF分页器」+ 与 exe 一致的淡粉双页应用图标。
- 右侧圆形最小化、关闭按钮；hover 时背景变为 `--pink-border`，关闭按钮 hover 变 `--error` 白字。

### 拖拽区

- 虚线边框 `2px dashed var(--pink-accent)`，居中显示 SVG 云朵/文件图标 + 「把 PDF 拖到这里，或点击选择文件」。
- 鼠标 hover：背景渐变为 `--pink-card`。
- 文件拖入悬停（dragover）：边框变实线 `--pink-deep`，背景加深，显示「松开即可导入」浮层；有呼吸/上浮动画。
- 支持 `.pdf` 文件；拖入其他类型时短暂红色抖动并提示「请拖入 PDF 文件」。

### 分段卡片

- 白色底（`#FFFFFF` 配粉边框）圆角卡片，左侧显示段号徽章（圆形，`--pink-accent` 底白字）。
- 每张卡片第一行包含：「起始页」输入框、「至」文字、「结束页」输入框、状态与删除按钮（垃圾桶图标，hover 变红）。
- 第二行提供「文件名（可选）」输入框并固定显示 `.pdf` 后缀；留空时使用默认名称，输入内容随「开始切分」统一提交，不单独保存。
- 输入框失焦或输入时即时校验：非法时边框与文字变 `--error`，卡片轻微左右抖动 0.3s，输入框下方出现一行 12px 红色提示。
- 「添加一段」按钮：虚线圆角按钮，带 `+` 图标；达到 10 段时隐藏。

### 主按钮与进度

- 「开始切分」主按钮：粉红渐变底（`#F4A0C0 → #E57CA6`）、白字、圆角 12px；hover 轻微上浮 1px，按下回弹。
- 主操作区固定在窗口内容底部；分段列表较长时只滚动内容区，主按钮保持可见。
- 切分中按钮变为「正在切分…」并禁用；下方出现细长圆角进度条（粉色渐变 + 圆头），每完成一段前进一格。
- 每张分段卡片右侧显示状态徽章：「等待中」（灰粉）、「处理中…」（旋转小圆圈）、「完成 ✓」（绿色）。

### 结果卡片

- 完成后在列表下方弹出浅绿底色结果卡片：每行显示可选择复制的文件名和明确的「打开」按钮，底部有「打开输出文件夹」按钮。

### 密码弹窗

- 需要密码时弹出居中模态卡片：粉色标题「需要密码」、说明文字、密码输入框（圆角，使用通用眼睛/闭眼图标显示或隐藏密码）、「取消」「确定」按钮。
- 密码错误时输入框红色抖动并提示「密码不正确，请重试」。

## 6. 动效标准

- 所有过渡统一 `transition: all 0.18s ease`。
- 拖入悬停动画：边框呼吸（`@keyframes pulse` 透明度 1→0.6→1，1.2s 循环）+ 拖拽区轻微上浮。
- 输入错误抖动：`@keyframes shake`，水平位移 `0 / -4px / 4px / -3px / 3px / 0`，共 0.3s。
- 按钮按压：`transform: translateY(1px)`。
- 卡片增删：新增时淡入上浮，删除时淡出收缩（0.2s）。
- 遵循系统减少动画偏好（`prefers-reduced-motion: reduce` 时关闭非必要动画）。
