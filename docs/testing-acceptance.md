# 测试与验收规范

## 1. 测试原则

- 每个阶段完成后，先跑本阶段验证项，再进入下一阶段。
- 手工测试为主（桌面应用交互），必要处加最小自动化校验（如命名规则函数）。
- 测试用的 PDF 文件统一放在 `test-fixtures/`（不入库的大文件除外）。
- 记录每个问题的现象、复现步骤、修复结果到 `devlog/DEVLOG.md`。

## 2. 测试用例矩阵

### A. 基础切分

| 用例 | 步骤 | 预期 |
| --- | --- | --- |
| A1 中文书籍 | 导入中文书名 PDF，切成 3 段 | 3 个文件页数与范围一致，内容完整无水印 |
| A2 含图片/扫描件 | 导入扫描 PDF 切 2 段 | 图片清晰度与原文件一致 |
| A3 单页 | 导入 1 页 PDF，默认段 1–1 | 正常输出 1 页文件 |
| A4 部分导出 | 300 页书只填 20–50 | 只生成该文件，无其他输出 |
| A5 重叠/跳页 | 段 1–10 与段 5–15 共存 | 两文件均正常生成 |

### B. 输入校验

| 用例 | 输入 | 预期 |
| --- | --- | --- |
| B1 | 起始页 0 | 红色提示 + 抖动，阻止切分 |
| B2 | 结束页大于总页数 | 同上 |
| B3 | 起始页大于结束页 | 同上 |
| B4 | 某段输入为空 | 同上 |
| B5 | 第 10 段时 | 「添加一段」按钮隐藏；可删除到只剩 1 段 |

### C. 加密与受限

| 用例 | 场景 | 预期 |
| --- | --- | --- |
| C1 受限文件 | 能看不能复制打印的 PDF | 直接切分成功，输出文件可正常打开打印 |
| C2 密码文件 | 需要密码打开 | 弹窗输入正确密码后成功 |
| C3 密码错误 | 输入错误密码 | 红色提示「密码不正确」，可重试 |
| C4 取消密码 | 弹窗点取消 | 回到导入前状态，无残留 |

### D. 命名与输出

| 用例 | 场景 | 预期 |
| --- | --- | --- |
| D1 特殊字符 | 文件名含 `：、（）空格` | 输出文件名正常，可打开 |
| D2 非法字符 | 含 `\ / : * ? " < > |` | 这些字符替换为 `_` |
| D3 重名 | 同名文件已存在 | 自动追加 `_2`，不覆盖原文件 |
| D4 输出目录 | 默认与自定义 | 默认生成「原文件名_分页结果」，自定义目录下不额外建子文件夹 |

### E. 打包与交付

| 用例 | 场景 | 预期 |
| --- | --- | --- |
| E1 干净环境 | 未装 Node/Python 的 Windows 10/11 | exe 双击可运行，界面正常 |
| E2 功能完整 | 打包版完整切 1 本书 | 与开发版行为一致 |
| E3 使用说明 | 小白按说明操作 | 不借助他人可完成一次切分 |
