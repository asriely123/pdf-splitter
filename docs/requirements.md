# 需求说明（Requirements）

## 1. 项目定位

「PDF分页器」是一个 Windows 桌面工具，解决用户用 WPS 切割 PDF 时因无会员产生水印的问题。目标用户是不懂代码的普通用户，因此交付物必须是一个双击即用的独立 exe，界面全程中文、操作直观。

## 2. 功能需求

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-1 | 导入 PDF | 支持点击选择文件与从系统拖入文件两种方式；一次处理一个 PDF |
| FR-2 | 显示信息 | 导入后显示文件名与总页数 |
| FR-3 | 分段管理 | 最少 1 段、默认 1 段、最多 10 段；可自由添加/删除分段 |
| FR-4 | 分段设置 | 每段填写「起始页」「结束页」，支持任意选择，不要求覆盖全书，允许段与段重叠；可选填写该段输出文件名 |
| FR-5 | 输入校验 | 起始页≥1、结束页≤总页数、起始≤结束；非法时明确提示并阻止切分 |
| FR-6 | 切分输出 | 按每段页码范围输出独立 PDF 文件，内容与原文件一致、无水印 |
| FR-7 | 受限/加密支持 | 无密码的「禁止复制打印」PDF 可直接切分；需密码的 PDF 弹窗输入密码，密码错误给出提示 |
| FR-8 | 输出位置 | 默认输出到原 PDF 同目录下「原文件名_分页结果」文件夹，也允许用户自行选择输出文件夹 |
| FR-9 | 文件命名 | 自定义名称留空时使用「原文件名_第N段_第X-Y页.pdf」；填写名称时自动补 `.pdf`，清理 Windows 非法字符；重名自动追加序号 |
| FR-10 | 进度与结果 | 切分过程逐段显示状态；完成后展示输出文件列表，可一键打开输出文件夹 |
| FR-11 | 窗口控制 | 自定义粉色标题栏，含最小化与关闭按钮 |

## 3. 非功能需求

- **易用性**：全程中文；拖入即用；错误提示用普通用户能懂的语言。
- **可靠性**：切分过程不损坏原文件；原 PDF 只读不写。
- **性能**：单文件切分在普通电脑上 10 秒内完成（视文件大小而定）；界面不卡死（异步处理）。
- **兼容性**：目标系统 Windows 10/11（64 位）。
- **安全**：密码仅存内存，不写盘、不写日志；渲染进程无 Node 权限。

## 4. 明确不做（v1 边界）

- 不批量处理多本 PDF（一次一本）。
- 不做页面缩略图预览。
- 不保留原 PDF 目录/书签。
- 不做 PDF 合并、压缩、加密输出等附加功能。
- 不提供在线功能，完全离线运行。

## 5. 验收标准

满足 docs/testing-acceptance.md 中全部测试场景，且打包后的 exe 可在未安装开发环境的 Windows 10/11 上双击运行。
